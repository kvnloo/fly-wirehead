# Research join (this repo is not the student)

This repository is an **I/O-remap demonstration** on the MaleCNS v1.0 LIF kernel: 90×160 RGB → R1–R6/R8, a 20 mV-equivalent current into 15 PAM11 cells while video plays, optional plasticity on 7,835 KC→MBON07/11 edges, and a choreographed swipe. The wiring is reconstructed; physiology, preference, pleasure, and addiction are **not** established. See [model.md](model.md) and [validation.md](validation.md).

It is **not** a trainable LLM, not a Qwen replacement, and not the FlyForge research student.

## What this repo *is* good for

- **Pinout reference:** which MaleCNS cells are driven by pixels, PAM11, and motor overlay.
- **Mechanism checks:** `--no-video-reward`, `--frozen`, separate `--run-dir` (already in [README](../README.md)).
- **Negative control for “the fly learned”:** the swipe shares an animation clock with the video transition; the feed is a timer.

## What not to add here

- A second AODL spec or a “fly version of Qwen” training loop.
- SWE-bench, TinyStories, or Hermes recovery as features of this Shorts app.
- Claims that PAM11 Hz is dopamine concentration or that KC→MBON weight change is addiction.

P0 of the research program is a **verified Hermes recovery controller** with a GRU baseline and a mandatory direct-input / rewire table, scored in joules per verified success. If that work needs MaleCNS arrays, consume them as a library from a separate experiment package — do not grow this demo into that package.
